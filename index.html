📦 Reims Desktop Official APT Repository

Official software repository for Reims Desktop (Ubuntu 24.04 LTS Noble).

Quick Setup

Add this repository to your system:

echo "deb [trusted=yes] https://joaosantiag0.github.io/reims-desktop noble main" | sudo tee /etc/apt/sources.list.d/reims.list
sudo apt update
sudo apt install reims-core reims-gui reims-vgpu

Packages Included

  • reims-core: System daemons, updater CLI, udev & udmabuf rules
  • reims-gui: Reims Desktop Control Center (Qt6 graphical interface)
  • reims-vgpu: Accelerated QEMU virtualization stack with Metal/Vulkan bridging

Reims Desktop is an independent unofficial community project.
